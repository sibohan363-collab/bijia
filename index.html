在手机上怎么用

苹果 / 安卓 · 1 分钟看完

第一步：放到手机桌面（只做一次）

苹果 iPhone：用 Safari 打开这个网页 → 点底部中间的分享按钮（方框加向上箭头）→ 往下滑，点“添加到主屏幕” → 点“添加”。桌面上就多了一个图标，以后点它就行。

安卓（华为、小米、OPPO、一加、vivo 等）：用 Chrome 打开 → 点右上角 ⋮ → 菜单往下滑，点“安装并创建快捷方式”（旧版叫“添加到主屏幕”）。用手机自带浏览器的话，点底部“菜单”，再点“添加到桌面”或“添加快捷方式”。

收到的是“双十一比价.html”文件：安卓手机在“文件管理”里点它，选 Chrome 打开就能用，不用联网也能比价。iPhone 打不开这种文件里的功能，要用网页链接。

在微信、QQ 里点开的链接：先点右上角 ··· → “在浏览器打开”，再按上面的方法添加。微信里也能用，但购物车可能存不住。

第二步：加商品

1. 在京东、淘宝或拼多多 App 里打开商品 → 点“分享” → 点“复制链接”。

2. 回到这个网页，长按“我的比价购物车”下面的输入框 → 点“粘贴” → 点“识别并加入”。

3. 在商品下面填价格：选好你要买的颜色、尺寸、版本后，填每个平台的到手价，别填搜索页上带“起”字的价格。没卖这件商品的平台空着不填。

4. 淘金币、国补这类页面价里还没扣的优惠，填到“每件还能再减”里。

第三步：看方案，自己去买

页面会给出最便宜的买法：在哪个平台买、拆成几单、领哪些券。点“打开原商品 ↗”会跳到京东、淘宝或拼多多 App，下单和付款都由你自己在 App 里完成。

在浏览器里点链接，一般会先打开平台的网页版，网页上的价格要登录才看得到。点网页上的“打开京东APP”或“立即打开”，要是弹出让你选用什么打开，选京东、淘宝或拼多多，就能跳进 App。平台有时会先让你做一次安全验证，照着提示点就行。

要注意的

· 不用注册，也不用登录。每个人打开的都是自己手机上的一份：购物车、银行卡设置、AI Key 都只存在自己手机里，别人看不到，也互不影响。

· 购物车只存在这部手机的这个浏览器里。换手机、换浏览器、用无痕模式，都看不到之前加的商品。

· 长时间不打开，浏览器可能会清掉这些记录，iPhone 尤其明显。重要的价格自己截图留一份。

· 价格随时会变，比如京东的限时补贴几分钟就变一次。下单前以平台页面上的到手价为准。

· 这个网页不需要、也不会保存你的京东、淘宝、拼多多账号密码。

AI 助手可选 · 用你自己的 API Key

每个人填自己的 Key，只存在自己的手机或电脑上，不会传给你或别人。你把 App 分享到朋友圈、家庭群，别人用的是他们自己的 Key，不会用到你的账号。价格还是由程序算，AI 只负责看懂乱七八糟的券规则、帮你检查方案。

商家藏起来的券，去哪找

很多券商家并不想让所有人都领到，所以不放在显眼的位置。下面是常见的藏法，以及 App 能帮到哪一步。

推广券（隐藏券）自动用上商品页上看不到，三家官方推广平台的接口能查到。通过本 App 的链接下单，券会自动带上，不用单独领。
店铺会员券 / 粉丝券排进领券队列要先加入店铺会员或关注店铺才发。领券时 App 直接跳到入会页，入会一般要授权手机号，值不值你自己定。
主会场红包、定时券到点提醒每天固定时段发，过了就没了。App 按时间点推送提醒，点提醒直接跳到抢券页。
购物车津贴、凑单券截图识别加入平台购物车后才显示。在平台购物车或结算页截图上传，App 识别后算进方案。
直播间券、问客服才给的券只能提醒接口查不到。App 会提示这家店常有直播券，或者提醒你问问客服。

领券

各方案要领的券对照
为什么不能在后台全自动领完？

领券这一步必须在你自己登录的京东、淘宝、拼多多 App 里点。别的 App 想替你在后台点，只能拿你的账号密码，或者读屏自动点击，这两种都违反平台规则，账号可能被封。

所以 App 做到“半自动”：隐藏推广券下单时自动带上；剩下的券一键排好队，自动一张张跳过去，你只用在每张上点一下“领取”，回来自动跳下一张。

套路提示

正式版怎么做到

  • 认出商品：分享出来的链接或淘口令，交给京东联盟、淘宝联盟（阿里妈妈）、多多进宝这三家官方推广平台的接口解析，拿到商品名、图片、详情、价格。现在演示版只能从分享文字里认出商品名，价格是随机编的。
  • 别的平台有没有同款：用商品名和规格去另外两个平台的接口搜，App 挑出最像的同款，让你确认是不是同一个东西。
  • 数据最新：App 背后放一个小服务器实时查接口，打开 App、加商品、下单前都会重查。接口密钥放在服务器上，不放进手机里。需要先申请开发者账号并通过审核。
  • 不做的事：不在 App 里登录这三家账号，不模拟登录，不读屏自动点击，不爬网页。这些违反平台规则，可能封号，也不安全。

计算规则按常见做法估算：店铺券和跨店满减按商品合计判断门槛，每单再用一张平台券，最后用红包；百亿补贴商品不参加店铺券和跨店满减；每个平台最多拆两单。实际以结算页为准。
